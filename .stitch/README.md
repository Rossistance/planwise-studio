### Dark variants

`dashboard.dark.html`, `schedule.dark.html`, `lookahead.dark.html` — the
"night-shift trailer" palette. Distinguished only by `data-theme="dark"` on
`<html>`; the light and dark rule sets are both inlined in every file.

### Why there are no separate mobile captures

PlanWise's responsive behaviour (tables reflowing into cards, 44px touch
targets, the look-ahead day grid wrapping into weeks) lives entirely in CSS
media queries, which are inlined in **every** file here. A narrow-viewport
capture produced a byte-identical file, so it would have been a duplicate
upload. View any of these at <720px to see the mobile form.

## The data is synthetic

Every job number, name, dollar figure, vendor, RFI and schedule task in these
files is **invented**. The captures come from an isolated instance seeded with
a fictional Vista workbook — real customer and financial data was never loaded,
so these files are safe to upload to a third-party service.

## Reproducing

The demo instance ran on port 8782 with `PLANWISE_DATA_DIR` and
`PLANWISE_VISTA_WORKBOOK` pointed at the session scratchpad, so the real
`~/.planwise` database and the OneDrive workbook were untouched. Seed scripts
(`seed_demo.py`, `seed_modules.py`) and the Puppeteer auth scripts live in that
scratchpad and are disposable.

Two things needed working around, worth knowing if this is run again:

- **The skill's `snapshot.ts` cannot load an `--auth-script` on Windows.** It
  passes a bare `D:\...` path to a dynamic `import()`, which Node rejects as an
  unsupported protocol. The captures used a patched copy that converts the path
  with `pathToFileURL` first.
- **Re-navigating to the same `#hash` after login is a same-document
  navigation**, so the SPA never re-runs its bootstrap and captures the
  signed-out placeholder. The auth scripts park on `about:blank` so the
  caller's re-navigation is a real document load.
- **Theme must be pinned explicitly.** With no `localStorage["planwise.theme"]`
  PlanWise follows `prefers-color-scheme`, and headless Chrome reported dark on
  this machine — an unpinned capture silently comes out in the wrong palette.
